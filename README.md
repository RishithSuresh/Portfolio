# Interactive 3D Universe Portfolio

A cinematic, sci-fi inspired portfolio built with **Next.js App Router**, **TypeScript**, **Tailwind**, **Three.js**, **React Three Fiber**, **Drei**, **GSAP**, and **Framer Motion**.

## Experience Highlights

- Intro sequence with cinematic reveal and ambient soundscape boot-up.
- Central star hub representing personal identity and mission.
- Thematic orbiting planets for:
  - AI Projects
  - Cybersecurity
  - Music Technology
  - Data Visualization
  - Experimental Projects
  - Contact / Resume
- Click-to-travel navigation with smooth camera easing and warp-like lens effects.
- Hover-reactive planets with holographic labels.
- AI hologram assistant HUD and integrated futuristic glass UI.
- Responsive and performance-aware rendering strategy (adaptive DPR, lightweight effects, lazy-loaded root scene).

## Tech Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Three.js + React Three Fiber + Drei
- GSAP
- Framer Motion
