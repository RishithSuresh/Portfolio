# Luxury Cinematic Portfolio

An Apple-inspired premium portfolio built with Next.js, Tailwind CSS, Framer Motion, GSAP-compatible animation foundations, React Three Fiber, and Lenis smooth scrolling.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion
- Three.js + React Three Fiber + Drei
- Lenis

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```
